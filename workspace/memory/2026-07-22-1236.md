The official yt-dlp docs describe exporting browser cookies into a text file with `--cookies-from-browser ... --cookies cookies.txt`, and they also note exporting YouTube cookies from a logged-in browser session. [yt-dlp FAQ](https://github.com/yt-dlp/yt-dlp/wiki/FAQ) [yt-dlp extractors wiki](https://github.com/yt-dlp/yt-dlp/wiki/Extractors)

So the two practical options are:

1. `YOUTUBE_DL_COOKIES_FROM_BROWSER=chrome`
- This means: “read cookies from the Chrome profile on the machine running cron.”
- Use `edge`, `firefox`, etc. if that is the browser you actually use.
- This only works if the cron host can access that browser profile.

2. `YOUTUBE_DL_COOKIES_FILE=/path/to/cookies.txt`
- This means: “use this exported cookie file.”
- You create it once from a browser where you are logged into YouTube.
- Cron then just reads the file, so this is the cleaner option for unattended jobs.

Example export flow:
```bash
yt-dlp --cookies-from-browser chrome --cookies /home/sam/youtube-cookies.txt "https://www.youtube.com/watch?v=VIDEO_ID"
```

Then in cron or the job wrapper:
```bash
YOUTUBE_DL_COOKIES_FILE=/home/sam/youtube-cookies.txt npm run youtube:transcript -- https://www.youtube.com/watch?v=VIDEO_ID
```

Or:
```bash
YOUTUBE_DL_COOKIES_FROM_BROWSER=chrome npm run youtube:transcript -- https://www.youtube.com/watch?v=VIDEO_ID
```

Important:
