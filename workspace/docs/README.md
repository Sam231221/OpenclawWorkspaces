# Workspace Docs

This folder holds human-readable documentation for the main Saara/OpenClaw
workspace.

## Current Docs

- `youtube_linkedin_workflow.md` - canonical policy and operating rules for the
  YouTube-to-LinkedIn workflow. Keep this updated when scheduler, state,
  delivery, approval, publishing, or asset rules change.
- `youtube_linkedin_systemd_timer.md` - focused reference for the active
  systemd timer, service, execution chain, state files, and troubleshooting
  commands.
- `youtube_linkedin_workflow_deep_dive.md` - historical/design deep dive for
  the YouTube digest and manual LinkedIn workflow.
- `transcriptapi_setup.md` - setup notes for the TranscriptAPI-only YouTube
  transcript helper.
- `AGENTS_FULL.md` - expanded local agent instructions kept as a reference.
- `TOOLS_FULL.md` - expanded local tool notes kept as a reference.

## Cleanup Policy

Keep canonical docs short enough to maintain. Move old experiments, raw
captures, or obsolete drafts to an archive instead of letting this folder become
a transcript dump.
