Vocabulary Entry Rules

Use these rules when building or validating each vocabulary entry.

There are two entry formats:

General Vocabulary — for ordinary vocabulary in semantic category pages.

Social / Slang / Internet Language — for slang, meme expressions, reaction phrases, insults, internet terms, and expressions whose real meaning depends heavily on tone or social context.

Choose the format first. Do not mix the field orders.

The templates are maximum useful-information models. Correctness is more important than filling a target count. Never invent linguistic information merely to make an entry look complete.

A. General Vocabulary Format

Use this format for ordinary/general vocabulary. It follows [Word](1).md.

Required Structure

Create one separate Notion section for each vocabulary item. Use this exact
field order and do not use tables. This is a semantic structure, not Markdown to
paste into Notion. Render labels in bold using Notion rich text annotations.

General Field Rules

Vocabulary Word

Exactly one target per heading.

Correct spelling.

Capitalise only when grammatically necessary.

Preserve phrasal verbs, idioms, and fixed expressions when they are being learned as one unit.

Prefer British spelling unless the source clearly targets another standard.

Type

Required.

Use the most useful common grammatical label(s): noun, verb, adjective, adverb, phrase, phrasal verb, idiom, etc.

Add countability or transitive/intransitive information only when it materially helps usage.

Put the most common use first.

Exclude rare or obsolete uses unless the screenshot specifically teaches them.

Pronunciation

Required when confidently known.

Use standard British IPA by default.

Add US pronunciation only when noticeably different and useful.

Do not invent IPA.

If pronunciation cannot be validated confidently, mark it under Needs review rather than guessing.

Meanings

Always include the primary meaning.

Add a secondary meaning only when it is common, useful, and genuinely distinct.

Maximum: 3 common meanings unless Mr. Sam asks for exhaustive coverage.

Use learner-friendly English.

Order meanings from most common to less common.

Label specialised, technical, figurative, formal, or informal senses when helpful.

Avoid repetitive paraphrases.

Register

Required when meaningful.

Typical labels: Neutral, Formal, Informal, Academic, Literary, Technical, Conversational.

Maximum: 2 labels unless a short warning is necessary.

Do not label an ordinary neutral word as formal/informal without reason.

Topics

Use 2-5 broad, reusable subject labels when naturally available.

Do not add unrelated topics to satisfy a count.

Prefer categories that help retrieval and recall.

Word Family

Include genuine commonly used related forms only.

Recommended: 3-6 forms; maximum: 8.

State the part of speech beside each form.

The original target may be included when useful.

If the family is genuinely limited, write: Limited common word family.

Do not fabricate derived forms.

Collocations

Target: 5 useful collocations when natural.

Recommended maximum: 10.

Prefer natural combinations useful in speaking and writing.

Do not include full example sentences.

Avoid trivial variations of the same collocation.

If fewer than five good collocations exist, include only the valid ones.

Common Patterns

Target: 4 useful patterns when natural.

Include common prepositions, verb structures, complements, sentence frames, and reusable grammar patterns.

Use placeholders such as someone, something, or ....

Distinguish grammar patterns from ordinary collocations.

Do not add technically possible but uncommon structures merely to reach a count.

Examples

Target: 5 natural examples.

Every example must use the exact target word/expression naturally.

Use complete, grammatical sentences.

Keep them concise and varied.

Prefer examples that demonstrate meaning, common collocations, grammar patterns, and register.

Avoid unverifiable statistics or unnecessary factual claims.

Do not create examples that contradict the meaning or usage notes.

Synonyms

Target: 3 when valid.

Use close synonyms or useful near-synonyms.

Add a short distinction in brackets when necessary.

Do not list merely related topic words.

If fewer than three valid synonyms exist, include only valid ones.

If there is no useful synonym, write: No close everyday synonym.

Antonyms

Target: 2 when valid.

Put direct antonyms first.

Use broader contrasts only when clearly labelled.

Do not invent antonyms.

When none exists, write: No direct antonym.

Commonly Confused With

Target: 1-2 genuinely confusable terms; maximum: 3.

Explain the difference clearly.

Confusion may come from spelling, pronunciation, form, or meaning.

When none exists, write: No commonly confused term.

Usage Notes

Use this section for information that helps the learner produce natural English:

important grammatical restrictions

countable/uncountable behaviour

transitivity

common prepositions

natural vs unnatural wording

UK/US differences when relevant

common learner mistakes

meaning or register restrictions

Do not repeat information already explained clearly elsewhere unless the repetition prevents a likely mistake.

My Note

Preserve Mr. Sam's existing personal note if present.

Never invent a personal history or claim he encountered the word somewhere that is not supported.

If the current task comes from an uploaded screenshot and no more specific source is visible, Source screenshot is acceptable for Where I found it.

What I want to remember may be a concise learner-oriented takeaway based on the entry, such as the most important usage distinction.

If a personal note cannot be added safely, write Not provided. rather than fabricating one.

Create one separate Notion section for each target. Use this exact field order

Social / Slang / Internet Field Rules

Word / Phrase

Preserve the complete expression as people actually use it.

Do not split a fixed reaction phrase or meme format into separate ordinary-word entries.

Preserve meaningful punctuation or stylised wording only when it is part of the expression.

If several variants exist, choose the most common display form and mention important variants under Common Patterns.

Type

Use the most useful functional label, not only a traditional part of speech.

Examples: slang noun, slang adjective, reaction phrase, meme expression, insult, idiom, internet term, gaming slang.

Maximum: 1-3 labels.

Prefer labels that explain how the expression functions socially.

Pronunciation

Provide IPA when the expression has a stable spoken pronunciation and it can be given confidently.

Use British English as the default pronunciation reference.

For written-only abbreviations, stylised spellings, or expressions whose pronunciation varies, explain that briefly instead of inventing IPA.

Mark uncertain pronunciation for review.

Meanings

Lead with the most common current social/internet meaning.

Add a secondary meaning only if it is genuinely useful.

Distinguish literal meaning from slang meaning when that distinction matters.

Avoid outdated niche senses unless they are relevant to the screenshot.

Register

Use labels such as Informal, Very informal, Slang, Vulgar, Offensive, Humorous.

Add a warning when the expression can be insulting, demeaning, vulgar, or risky with unfamiliar people.

Do not soften a strong insult into a neutral label.

Tone

Explain likely interpersonal tone: positive, playful, teasing, sarcastic, mocking, dismissive, rude, aggressive, admiring, ironic, etc.

Multiple tones may be listed when context changes the effect.

If tone is highly context-dependent, say so explicitly.

Intensity

Use:

Mild

Medium

Strong

Judge intensity by likely social impact, not only dictionary meaning.

For insults or confrontational phrases, consider how harsh the expression sounds when directed at a real person.

Topics

Use broad social/internet topics such as Internet culture, Social interaction, Gaming, Humour, Conflict, Dating, Streaming, Comments, Memes, Online communities.

Maximum: 5 unless Mr. Sam asks for more detail.

Do not add unrelated topics.

Word Family / Related Forms

Include genuine related forms, common variants, abbreviations, or derivations.

If ordinary word-family analysis is not useful, write:
Not particularly useful for this expression.

Do not invent derivations from memes or slang.

Common Collocations / Combinations

Include natural combinations people actually use with the target.

For phrases, this may include common lead-ins, follow-ups, intensifiers, hashtags, or paired expressions.

Prefer 3-6 strong combinations rather than weak filler.

Do not turn full example sentences into collocations.

Common Patterns

Focus on real usage forms, including:

typical sentence placement

common reply/reaction structure

meme-template variations

X + target or target + X constructions

frequent online formatting

common grammatical substitutions

Avoid manufactured patterns that are not actually common.

Examples

Target: 5 examples when enough distinct contexts exist.

Include a mix of casual conversation and online/comment-style usage when relevant.

Show different tones where useful.

Include an example demonstrating potential rudeness when that is important to safe usage.

Every example must use the exact target expression or a clearly identified grammatical variation.

Keep examples non-graphic and learner-friendly.

Social Meaning & Context

This section is essential.

What is usually happening?

Explain the social scene in which the expression appears: teasing, joking, reacting to failure, praising someone, mocking confidence, arguing, flirting, commenting on content, etc.

What does the speaker imply?

Explain what is communicated beyond the literal words: approval, disbelief, ridicule, status judgement, sarcasm, criticism, affection, dismissal, exaggeration, etc.

Literal or figurative?

Choose the best label:

Literal

Figurative

Usually figurative

Context-dependent

Explain briefly when needed.

When People Use It

Give 2-4 realistic situations.

Describe situations, not just platforms.

Make clear when the expression is mostly online versus also common in ordinary speech.

Usage Guidance

This section is essential for socially loaded language.

Safe to use

Choose one:

Yes

Usually

Sometimes

Better to avoid

Add a short reason when necessary.

Common with

State the likely audiences/settings, such as friends, gaming, comments, memes, casual conversation, familiar peers.

Avoid with

State contexts where the expression may sound inappropriate, such as teachers, workplace, strangers, formal writing, unfamiliar adults, or serious conflict.

Do not encourage the learner to use aggressive or offensive language merely because it is common online.

Synonyms / Similar Expressions

Prefer expressions that are similar in social effect, not merely dictionary synonyms.

Briefly distinguish stronger/weaker alternatives when useful.

If there is no close equivalent, write: No close equivalent.

Opposite Ideas / Antonyms

Direct antonyms are often unavailable for slang.

Use opposite social ideas only when meaningful.

Do not invent artificial antonyms.

If none exists, write: No direct opposite expression.

Commonly Confused With

Include genuinely similar slang, meme phrases, or ordinary words a learner may mix up.

Explain the difference in meaning, tone, or context.

If none exists, write: No commonly confused term.

Related Internet / Social Expressions

Include 2-5 genuinely related current expressions when useful.

Related means they occur in the same social/semantic area, not simply that they are popular online.

Do not force this section with unrelated slang.

My Observation

Preserve Mr. Sam's existing observation if present.

Never invent a platform, creator, conversation, or social event.

If the item came from the current screenshot and the exact platform is not identifiable, write Source screenshot.

Fill Original situation only from visible/provided context; otherwise write Not clear from the screenshot.

What confused me is optional and should not be fabricated.

My understanding may contain a concise learner-friendly interpretation produced from the completed entry, but should not pretend to quote Mr. Sam.

Shared Validation Rules

Before writing any entry, check:

The correct format (general or social_internet) was selected.

The heading contains exactly one target vocabulary item/expression.

The field order matches the selected format exactly.

Spelling is correct and meaningful punctuation is preserved.

Grammatical/functional labels are plausible.

IPA is present only when confidently supported.

Meanings are distinct and current.

Register is appropriate.

Topics are relevant.

Word-family/related-form items are genuine.

Collocations/combinations are natural.

Patterns are reusable and common.

Every example contains the target expression naturally.

Synonyms/similar expressions are meaningfully related.

Antonyms/opposite ideas are not fabricated.

Confused terms include a clear distinction.

Usage notes/guidance do not contradict the examples.

Social entries explain implication and context, not only dictionary meaning.

Personal-note/observation fields do not invent personal history.

There are no duplicate list items.

British spelling is used consistently unless an alternative is explicitly relevant.

Existing useful notes are preserved when expanding an entry.

The entry has been converted to Notion block JSON before writing.

No presentation-only Markdown markers such as `**`, `***`, `##`, or Markdown
list prefixes remain in Notion `text.content` values.

Field labels are represented as label text plus Notion bold annotations, not as
asterisk-wrapped strings.

If validation fails, correct safe formatting issues automatically. Do not save unsupported linguistic information; mark unresolved uncertainty for review.
