**Cloud Computing and Multicloud: Right vs Wrong**

Cloud computing gives teams access to storage, databases, and computing resources on demand, while multicloud strategies can reduce dependence on a single vendor. However, the claims below show that these benefits are real, but not absolute. Cloud and multicloud each introduce their own trade-offs around cost, governance, security, and risk.

- A multicloud solution reduces reliance on a single vendor.
- Leveraging the cloud instead of maintaining our own on-premises data center allows us to use only the resources we need, when we need them.

**Incorrect statements**
- EC2, S3, and RDS are solutions offered by Microsoft Azure.
- Cloud computing reduces all kinds of risk.
- Multicloud solutions reduce security and governance concerns.

**Key takeaway**
Cloud computing is about flexible access to infrastructure and managed services, not risk elimination. Multicloud can improve resilience and vendor flexibility, but it does not automatically simplify security or governance. In practice, these strategies help most when they are paired with strong architecture, clear ownership, and careful controls.
